## Source

- Normal = site sm-mark.svg (ink square, cream chevron). Inverted = site sm-mark-dark.svg (coral square, ink chevron), the mark the site shows in dark mode.
- horizontal-sprint-mode.png = site sm-lockup.svg; horizontal-sprint-mode-dark.png = site sm-lockup-dark.svg.
- horizontal-sprint-mode-inverted.png = coral mark + ink wordmark (light backgrounds).
- horizontal-sprint-mode-inverted-dark.png = the mark with its two colours swapped (cream square, ink chevron) + cream wordmark: the one colourway not taken directly from the site; use -dark first.
- Wordmark: the site lockup text "Sprint Mode" (Geist Bold 17px, -0.3 tracking) converted to outlines; no font needed.
- og-sprint-mode-inverted.png uses the site dark background #141311.
